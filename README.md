# Weekly HW Checker — что это и как поднять

Идея: раз в неделю ты берёшь `weekly-hw-template.html`, копируешь в новый файл,
меняешь заголовок и список вопросов (`QUESTIONS`), а проверка ответов
происходит НЕ в браузере ученика (как в первом варианте со скриншотом),
а на сервере — в Google Apps Script, привязанном к твоей Google Sheet.
Поэтому оценку нельзя подделать через DevTools: ученик физически не видит
ни правильных ответов, ни логики проверки — только вопрос и поле ввода.

Результат ученик видит сразу на странице (процент + разбор по каждому
вопросу), а у тебя в таблице автоматически появляется строка с его именем,
баллами и временем отправки — без единого скриншота и без ручной проверки.

## 1. Разовая настройка (займёт ~20–30 минут один раз)

### Шаг 1 — создай Google Sheet
Создай новую таблицу, например "HW Checker — 9 класс". Внутри сделай два листа:

**Лист `AnswerKey`** (ключ ответов, ученик его не видит) — заголовки в первой строке:

| WeekID | QuestionID | Type | CorrectAnswer | Tolerance | Points | Hint |
|---|---|---|---|---|---|---|
| week-01 | q1 | numeric | 5 | 0 | 1 | Перенеси 5 в другую часть, потом раздели на 3 |
| week-01 | q2 | text | x+6 | | 1 | Раскрой скобки: 2x+6−x |
| week-01 | q3 | mc | b | | 1 | Подставь x=0 и проверь, при каком уравнении не совпадёт |

Пояснения по колонкам:
- **Type**: `numeric` (число, сверяется с допуском Tolerance), `text` (строка,
  без учёта регистра/пробелов) или `mc` (multiple choice — сверяется как text
  с value варианта, например `a`/`b`/`c`).
- **CorrectAnswer**: для `text`/`mc` можно указать несколько принимаемых
  вариантов через `|`, например `x+6|6+x` — оба варианта засчитаются.
- **Tolerance**: только для `numeric`, допустимая погрешность (0 — точное
  совпадение, 0.01 — если в вопросе десятичные дроби).
- **Hint**: короткая подсказка, которую ученик увидит, если ответил неверно
  (это и есть "разбор ошибок").

**Лист `Responses`** (лог сдач, заполняется автоматически) — заголовки:

`Timestamp | StudentName | WeekID | Earned | Possible | Percent | AnswersJSON | FeedbackJSON`

Строки сюда добавляет сам скрипт — вручную ничего вписывать не нужно.

### Шаг 2 — подключи Apps Script
В этой же таблице: **Extensions → Apps Script**. Удали содержимое по
умолчанию, вставь туда файл `Code.gs` целиком. Сохрани (значок дискеты).

### Шаг 3 — задеплой как веб-приложение
**Deploy → New deployment** → тип **Web app**.
- Execute as: **Me**
- Who has access: **Anyone**

Нажми Deploy, разреши доступ (Google спросит про права на таблицу — это
нормально, скрипту нужно читать/писать в неё). Скопируй **Web app URL** —
он понадобится в HTML-шаблоне.

### Шаг 4 — пропиши URL в HTML
Открой `weekly-hw-template.html`, в блоке `CONFIG` вставь скопированный URL
в `SCRIPT_URL`.

## 2. Что делать каждую неделю

1. Скопируй `weekly-hw-template.html` в новый файл (например `week-02.html`).
2. Поменяй в `CONFIG`: `WEEK_ID` (например `"week-02"`), `PAGE_TITLE`.
3. Отредактируй массив `QUESTIONS` — тексты вопросов и их `type`
   (правильные ответы сюда **не** пишутся — они идут только в Google Sheet).
4. Добавь в лист `AnswerKey` новые строки с тем же `WeekID`, что в `CONFIG`,
   и правильными ответами/подсказками для каждого `QuestionID`.
5. Разошли HTML-файл ученикам (см. ниже про хостинг).

Сам `Code.gs` трогать не нужно — он не меняется от недели к неделе.

## 3. Как раздать файл ученикам

Открытие HTML напрямую как локального файла иногда блокирует отправку
из-за ограничений браузера на `file://`. Надёжнее всего бесплатно
захостить: например GitHub Pages (закинуть файл в репозиторий, включить
Pages в настройках) или Google Sites (вставить HTML через embed). Если
Claude Code настроен на деплой — можно попросить его сразу поднять
GitHub Pages для этого репозитория, это 5 минут разовой настройки.

## 4. Ограничения, о которых стоит знать

- **Тип ответа `text` — это точное (посимвольное, без пробелов/регистра)
  сравнение строк**, а не проверка математической эквивалентности. Если
  ожидаешь несколько равнозначных форм ответа (`x+6` и `6+x`), перечисли
  их все в `CorrectAnswer` через `|`. Полноценную алгебраическую проверку
  (когда система сама понимает, что `2(x+3)` и `2x+6` — одно и то же)
  Apps Script "из коробки" не умеет — это отдельная, более сложная фича.
- Эта система защищает от подделки результата через DevTools/консоль
  (сервер — единственный источник правды), но не защищает от того, что
  ученик спросит правильный ответ у одноклассника или у другого ИИ и
  честно его впишет. Это уже не техническая проблема, а вопрос дизайна
  самого задания (например, часть вопросов делать без готового ответа в
  интернете).
- Бесплатных квот Google Apps Script с запасом хватает на класс/несколько
  классов в неделю — это не про масштаб школы на тысячи учеников, но для
  твоей нагрузки более чем достаточно.

## 5. Что отдать Claude Code

Все три файла (`Code.gs`, `weekly-hw-template.html`, этот README) — как
техническое задание. Стоит попросить его: (1) помочь пройти деплой шаг за
шагом, (2) поднять простой бесплатный хостинг для HTML (GitHub Pages),
(3) при желании — сделать так, чтобы вопросы тоже подтягивались из
Google Sheet, а не переписывались в HTML руками каждую неделю (это
следующий шаг усложнения, если ручное редактирование QUESTIONS начнёт
надоедать).
