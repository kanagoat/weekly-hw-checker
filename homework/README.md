# Generated homework

Question banks for the HW Checker, written to match the AnswerKey sheet's
column order exactly so they can be pasted straight in.

## What's here

| File | Contents |
|---|---|
| `grade10-week-01.tsv` | Grade 10, `week-01` — Coordinate geometry I (PM1 §3.1–3.3), 20 questions |
| `grade10-week-02.tsv` | Grade 10, `week-02` — Coordinate geometry II (PM1 §3.4–3.5), 20 questions |
| `grade10-coordinate-geometry.tsv` | Both weeks in one file, 40 rows |
| `REVIEW-grade10-chapter3.md` | All 40 questions with answers, hints and solutions, for checking before you assign them |

Source: *Cambridge International AS & A Level Mathematics: Pure Mathematics 1*
(Pemberton, CUP 2018), Chapter 3 — matched to the IQanat High School of Burabay
10th grade AS-level 2025–26 plan, which gives Chapter 3 nine hours across
five topics.

## How to load a week into the sheet

1. Run **HW Checker → First-time setup: 1) Init structure** once, if you
   haven't already. The TSV files include a `Grade` column, and that command
   is what adds it to `AnswerKey`.
2. Open `AnswerKey` and click the first empty cell in column **A**.
3. Open the `.tsv` file in a text editor, select everything **except the
   header row**, and copy.
4. Paste. Sheets splits tab-separated text across columns automatically, so
   the 11 columns land in `WeekID … Grade` in order.
5. Check that column K (`Grade`) reads `10` on the new rows, and that column E
   (`Tolerance`) shows `0` and not a date — see the warning below.

Then the week is live at:

```
https://kanagoat.github.io/weekly-hw-checker/weekly-hw-template.html?week=week-01&grade=10
```

### Watch the number formatting

Sheets can turn plain values into dates depending on your locale. Before
pasting, select columns **D** (`CorrectAnswer`) and **E** (`Tolerance`) and set
**Format → Number → Plain text**. Question `week-01 q7` has the answer `-1/6`
and `week-02 q13` has `-3/4`; without plain-text formatting Sheets may store
those as dates or as decimals, and the question will then always grade wrong.

## Regenerating

The questions are generated by scripts that recompute every answer from the
underlying points and assert it, so a wrong key fails the build rather than
reaching a student. The scripts also check that:

- every multiple-choice `CorrectAnswer` is one of its own `Choices`, and that
  exactly one choice grades as correct;
- no two choices become identical once the grader strips case and whitespace;
- every `$…$` span parses under KaTeX;
- a port of `checkAnswer()` from `Code.gs` marks each key's own answer right
  and a clearly wrong answer wrong.

The scripts are in `generator/`. To rebuild everything from this directory:

```bash
cd homework/generator
python emit.py ..                                  # regenerates the .tsv files
python review.py ../REVIEW-grade10-chapter3.md     # regenerates the review doc
python grade_sim.py ../grade10-week-0*.tsv         # re-runs the grading simulation
```

`emit.py` refuses to write anything if a question fails validation. To add a
chapter, copy `week02.py` as a starting point and add it to the `WEEKS` list in
`emit.py`.
